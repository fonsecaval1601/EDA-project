# 🎵 Maven Music Churn Analysis
## Data Foundation Project for Customer Retention Strategy

### 📋 Project Overview
Business Challenge
Maven Music, a growing music streaming service, has been experiencing higher-than-usual customer churn over the past few months. As the newly hired Junior Data Scientist, I was tasked with building the analytical foundation to understand customer behavior patterns and identify key drivers of subscription cancellations.

Project Scope
This foundational project established the complete data pipeline and analytical framework needed to address customer churn, setting the stage for future predictive modeling and retention strategy development.

### 🎯 Project Objectives
Objective	Description	Status

✅ Scope Project	Define analytical approach using available customer data	Completed.

✅ Gather Data	Integrate customer profiles, subscription details, and listening history	Completed.

✅ Clean Data	Handle missing values, correct inconsistencies, standardize formats	Completed.

✅ Explore Data	Analyze patterns, correlations, and churn drivers	Completed.

✅ Prepare for Modeling	Engineer features and create modeling-ready dataset	Completed.




### 📊 Key Findings

Churn Rate Analysis

| Metric                              | Value                       |
| ----------------------------------- | --------------------------- |
| Overall Churn Rate                  | **43%**                     |
| Cancelled Customers                 | **13 of 30**                |
| Avg. Membership Before Cancellation | **~46 days**                |
| Peak Cancellation Period            | **Days 30–60 after signup** |

### 💰 Discount Strategy Impact

| Customer Segment   | Churn Rate | Key Insight                                  |
| ------------------ | ---------- | -------------------------------------------- |
| Discount Customers | **85.7%**  | **2.8× higher churn** than regular customers |
| Regular Customers  | **30.4%**  | More stable subscriber base                  |

### 🎧 Listening Behavior Patterns

| Metric               | Retained Customers | Cancelled Customers | Difference / Insight  |
| -------------------- | ------------------ | ------------------- | --------------------- |
| Avg. Sessions        | **3.8 sessions**   | **2.1 sessions**    | **−45% engagement**   |
| Pop Music Preference | Lower %            | Higher %            | Correlates with churn |
| Content Diversity    | More varied        | Less varied         | Retention indicator   |

### 📈 Subscription Tier Analysis

| Subscription Tier | Churn Insight                       |
| ----------------- | ----------------------------------- |
